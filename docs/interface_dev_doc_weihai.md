# 1. 系统说明

该接口用于 **威海政务服务云平台调用省办件归集系统的数据下发服务**。  
接口采用 **SM2 + SM4 混合加密机制** 进行通信。

开发系统需要：

- 使用 SM2 公钥加密 SM4 密钥
- 使用 SM4 加密业务 data 报文
- 在 header 中传递加密后的 SM4 密钥
- 在 body 中传递 SM4 加密后的 data

# 4. SM2 公钥

用于 **加密客户端生成的 SM4 密钥**。

```
04b40e6e436223fb6c2460e9c00b60d724bf03944f8cf379df6cdbdfe07253ede0073dae5428927cc04312f9aadfb19eb36b1820947f19ee590890fad5b428c4b2
```

开发流程：

1. 客户端生成随机 **SM4 密钥**
2. 使用该 **SM2 公钥** 加密 SM4 密钥
3. 将 SM2 加密后的 SM4 密钥放入 Header
4. 使用 SM4 加密 data 报文

---

# 5. 加密通信流程

## 5.1 请求流程

```
客户端
  │
  │ 1 生成随机 SM4 密钥
  │
  │ 2 SM4 加密业务 data
  │
  │ 3 使用 SM2 公钥加密 SM4 密钥
  │
  │ 4 发送 HTTP 请求
  │
  ▼
服务端
```

请求结构示例：

### Header

```
token: 300f5294b6f949feaf36b3cccacbba20
encryptKey: SM2加密后的SM4密钥
Content-Type: application/json
```

### Body

```
{
  "data": "SM4加密后的业务报文"
}
```

---

# 6. 响应流程

服务端返回数据通常也是 **SM4 加密内容**。

处理流程：

```
服务端返回密文
        │
客户端使用 SM4 密钥解密
        │
得到真实 JSON 数据
```

示例响应结构：

```
{
  "code": "0",
  "message": "success",
  "data": "SM4加密密文"
}
```

解密后：

```
{
  "total": 100,
  "items": []
}
```

# 8. 开发注意事项

1. SM4 密钥必须 **每次请求随机生成**
2. SM2 仅用于 **加密 SM4 密钥**
3. data 报文必须先转为 JSON 字符串再加密
4. Header 与 Body 字段名需要与接口文档一致
5. 响应 data 字段需要使用 **同一个 SM4 密钥解密**
6. token 不应暴露给前端，只能在后端配置

# 9. 推荐系统调用流程

```
前端输入参数

      ▼

      │
生成 SM4 密钥
      │
SM4 加密 data
      │
SM2 加密 SM4 密钥
      │
调用外部接口
      │
获取响应
      │
SM4 解密响应
      │
返回前端展示
```

# 10. 适配本系统的关键开发点

模块名称建议：

```

 ├─ sm2_service.py

```

能力：

- SM4 密钥生成

模块名称：

```
query_executor_service.py
```

职责：

- 读取接口配置
- 组装 data
- 执行 SM2 + SM4 加密
- 调用远程接口
- 解密响应
- 返回标准化结果

---

```
remote_api_adapter.py
```

职责：

- Header 组装
- HTTP 请求发送
- 错误处理
- 重试机制
